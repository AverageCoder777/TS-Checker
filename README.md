Данная программа призвана заменить/объединить/улучшить функционал TS Tools (RWTools).

Реализовано:
Система показа маршрутов с загрузкой миниатюр, показ списка сценариев
Система проверки выбранного маршрута на недостающие (утерянные/ненайденные) объекты + система просмотра списка всех объектов маршрута с указанием тайлов и числа использований
Система замены выбранного объекта маршрута на любой выбранный объект на диске (с запретом редактирования тайлов папки Network и файла Tracks.bin). Также существует возможность выбирать файлы, хранящиеся в .ap архивах
Система просмотра составов выбранного сценария с проверкой их наличия и предложением заменить утерянные составы через LocoSwap (требуется кастомный fork приложения, который умеет принимать параметры запуска для открывания окна редактирования сразу нужного сценария).
Система аудита: проверка выбранной папки любого дополнения на целостность (из bin достаются ссылки на другие файлы (geopcdx -> TgPcDx, ban, out, lua, xsec и т.д.) и проверяется их существование)
Система расшифровки любого bin/geopcdx файла и открытия в текстовом редакторе (пока работает только VS Code). При сохранении отредактированного файла через VS Code он шифруется в исходный формат и исходное место, а оригинальный файл получает расширение .bak<номер копии>

В планах: прикрутить локализацию и настройку добавления других текстовых редакторов кроме VS Code.
