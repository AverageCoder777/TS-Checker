Данная программа призвана заменить/объединить/улучшить функционал TS Tools (RWTools) и LocoSwap.

На данный момент по функционалу маршрутов: проверка маршрутов на утерянные файлы; отображение все используемых на маршруте файлов с указанием тайлов, где они встречаются; замена утерянных файлов, поиск сломанных символов (французская и немецкая раскладки) в файлах и переименование их на английский с коррекцией всех ссылок, связанных с этими файлами

По функционалу сценариев: просмотр сценариев маршрута; автоматическая проверка наличия подвижного состава в сценарии.

В планах: добавить замену любого подвижного состава и его нумерацию.
