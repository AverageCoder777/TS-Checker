# TSC Check Tool

Инструмент для анализа, проверки и модификации контента в **Train Simulator**, призванный объединить, улучшить и заменить базовый функционал **TS Tools (RWTools)**.

---

## 🚀 Текущий функционал

* **Маршруты и сценарии**
  * Просмотр списка установленных маршрутов с автоматической подгрузкой миниатюр.
  * Отображение доступных сценариев для выбранного маршрута.

* **Проверка и замена объектов**
  * Поиск недостающих, утерянных и ненайденных ассетов на выбранном маршруте.
  * Просмотр полного списка объектов маршрута с привязкой к тайлам и счетчиком количества использований.
  * Замена любых объектов маршрута на файлы с диска или напрямую из архивов `.ap`.
  * *Защита:* встроен запрет на редактирование файлов `Tracks.bin` и тайлов директории `Network`.

* **Составы и подвижной состав**
  * Просмотр составов в выбранном сценарии с верификацией их наличия.
  * Быстрая отправка на замену отсутствующего ПС через **LocoSwap** *(требуется кастомный форк с поддержкой аргументов командной строки для прямого открытия сценария)*.

* **Аудит целостности аддонов**
  * Глубокая проверка выбранной папки дополнения на целостность зависимостей.
  * Автоматический парсинг файлов `.bin` и проверка физического наличия связанных ресурсов (`geopcdx` → `TgPcDx`, `.ban`, `.out`, `.lua`, `.xsec` и др.).

* **Работа с бинарными файлами**
  * Встроенная дешифровка любых `.bin` и `.geopcdx` файлов с открытием в текстовом редакторе *(на данный момент поддерживается VS Code)*.
  * Автоматическая обратная компиляция и шифрование в исходный формат и каталог при сохранении файла.
  * Автоматическое создание резервных копий с суффиксом `.bak<номер_копии>`.
