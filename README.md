Данная программа призвана заменить/объединить/улучшить функционал TS Tools (RWTools).

На данный момент по функционалу маршрутов: проверка маршрутов на утерянные файлы; отображение все используемых на маршруте файлов с указанием тайлов, где они встречаются; замена утерянных файлов

По функционалу сценариев: просмотр сценариев маршрута; автоматическая проверка наличия подвижного состава в сценарии, открывание сценария в LocoSwap для замены недостающего состава.

В планах: добавить замену любого подвижного состава и его нумерацию, поиск сломанных символов (французская и немецкая раскладки) в файлах и переименование их на английский с коррекцией всех ссылок, связанных с этими файлами
